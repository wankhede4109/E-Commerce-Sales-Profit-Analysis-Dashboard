# E-Commerce-Sales-Profit-Analysis-Dashboard
I created this E-Commerce Sales & Profit Analysis Dashboard using Microsoft Power BI to analyze business performance and present key insights through an interactive and visually engaging report.

The dashboard includes YTD Sales, YTD Profit, YTD Quantity, YTD Profit Margin, YOY Sales, customer region analysis, product performance, category performance, and shipping-type analysis.

   Key Highlights
1.  Used DAX functions and measures for YTD, PYTD, YOY growth, profit margin, and other business calculations.
2.  Used the UNICHAR() DAX function to dynamically display ▲ for positive growth and ▼ for negative growth.
3.  Applied conditional formatting to show positive and negative performance using green and red indicators.
4.  Used a Map visual to analyze sales across different customer regions.
5.  Used Bar Charts, Donut Charts, KPI Cards, Tables/Matrix, and Map visuals to present insights clearly.
6.  Compared YTD Sales, PYTD Sales, and YOY Sales to understand sales growth and performance.
7.  Added interactive elements to make the dashboard easier to explore and analyze.

   Tools & Skills

Power BI | DAX | Power Query | Data Visualization | Business Intelligence | Data Analysis
